### Tokens

_Tokens are the smallest unit of any programming language. It is a building block of programming language. It has been categorised in multiple types._

- Keywords: Keywords are reserved words. It is already defined.
- Identifiers: It is the name of variables. It has certain rules
  1. It can't start with numbers
  2. Special symbols are not allowed as an identifier except `$` and `_`
  3. Identifiers should not contain white space.
  4. Keywords are not allowed as an identifiers
  5. Identifiers are case sensitive.
- Literals: Literals are actual data all of these data are having some types. It has been categorised in two types.
  1. Primitive
  2. Non-Primitive
- Separators: It is a special symbol used to provide separation of concern to the code
- Operators: It is a special symbol used to perform some specific task based on operands.

### Data Types in JavaScript

_There are two types of datatypes in JavaScript Primitive and Non-Primitive._

_Primitive data types are also known as single value data type. there are total 7 primitive datatypes._

_Non-Primitive datatypes are known as multi value datatype. It can store multiple values in a same variable. There are three non-primitive datatype._

### Differences between Primitive and Non-Primitive

| Primitive                                                | Non-Primitive                                     |
| -------------------------------------------------------- | ------------------------------------------------- |
| Only one value can be stored                             | Multiple value can be stored in a single variable |
| Value based                                              | Reference based                                   |
| Immutable                                                | Mutable                                           |
| Number, String, Boolean, Null, Undefined, bigint, Symbol | Array, Object and Function                        |
